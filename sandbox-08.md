## Завдання 1. Лічильник слів

**Файл:** `sandbox-08/task1.cpp`

### Опис завдання

Реалізувати програму, яка визначає кількість слів у текстовому рядку. Роздільниками слів вважаються пробіли, коми та символи табуляції.

Програма повинна правильно обробляти декілька роздільників поспіль, не враховуючи їх як окремі слова.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task1.cpp -o /tmp/sandbox08-task1
/tmp/sandbox08-task1
```

### Результат перевірки

```text
3 2
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `3 2` | `3 2` | У першому рядку міститься три слова, а в другому — два, оскільки послідовні роздільники не враховуються як слова. |

### Додаткові варіанти для демонстрації

Програма не використовує інтерактивне введення. Для перевірки інших рядків можна змінювати виклики `count_words()` у функції `main()`.

| Рядок | Очікувана кількість слів |
|---|---|
| `"hello world"` | `2` |
| `"one,two,three"` | `3` |
| `"a,,b"` | `2` |
| `"   "` | `0` |
| `"hello"` | `1` |

Наприклад, замінити в `main()` виведення на:

```cpp
std::cout << count_words("hello world") << ' '
          << count_words("a,,b") << '\n';
```

**Очікуваний результат:**

```text
2 2
```

Після зміни коду повторно виконати:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task1.cpp -o /tmp/sandbox08-task1
/tmp/sandbox08-task1
```

## Завдання 2. Калькулятор на один рядок

**Файл:** `sandbox-08/task2.cpp`

### Опис завдання

Реалізувати простий калькулятор, який обробляє арифметичний вираз, що складається з двох невід'ємних цілих чисел та одного арифметичного оператора.

Програма підтримує додавання, віднімання й множення. Також вона перевіряє наявність зайвих символів після другого числа та виводить позицію першого такого символу.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task2.cpp -o /tmp/sandbox08-task2
/tmp/sandbox08-task2
```

### Результат перевірки

```text
46
error at 3
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `46` та `error at 3` | `46` та `error at 3` | Перший вираз обчислюється правильно, а в другому після числа виявлено зайвий символ `x` на позиції 3. |

### Додаткові варіанти для демонстрації

Для перевірки інших виразів можна змінювати рядки `calculate()` у функції `main()`.

| Вираз | Очікуваний результат |
|---|---|
| `"10+5"` | `15` |
| `"20-7"` | `13` |
| `"4*6"` | `24` |
| `"5+3x"` | `error at 3` |
| `"100-25"` | `75` |

Наприклад:

```cpp
int main() {
    calculate("20-7");
    calculate("4*6");
}
```

**Очікуваний результат:**

```text
13
24
```

Повторна компіляція та запуск:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task2.cpp -o /tmp/sandbox08-task2
/tmp/sandbox08-task2
```

## Завдання 3. Шістнадцяткові числа

**Файл:** `sandbox-08/task3.cpp`

### Опис завдання

Реалізувати програму для перетворення шістнадцяткових чисел у десяткові.

Програма обробляє символи цифр від `0` до `9` та літери від `A` до `F` або від `a` до `f`.

Для перетворення використовується функція `hex_value()`, яка послідовно обчислює десяткове значення числа.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task3.cpp -o /tmp/sandbox08-task3
/tmp/sandbox08-task3
```

### Результат перевірки

```text
65 255 418
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `65 255 418` | `65 255 418` | Числа `0x41`, `0xff` і `0x1A2` правильно перетворено із шістнадцяткової системи в десяткову. |

### Додаткові варіанти для демонстрації

Для інших значень потрібно змінити аргументи функції `hex_value()` у `main()`.

| Шістнадцяткове число | Очікуваний десятковий результат |
|---|---|
| `0x10` | `16` |
| `0xFF` | `255` |
| `0xA` | `10` |
| `0x2B` | `43` |
| `0x100` | `256` |

Наприклад:

```cpp
int main() {
    std::cout << hex_value("0x10") << ' '
              << hex_value("0x2B") << '\n';
}
```

**Очікуваний результат:**

```text
16 43
```

Повторна компіляція та запуск:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task3.cpp -o /tmp/sandbox08-task3
/tmp/sandbox08-task3
```

## Завдання 4. Однозв'язний список

**Файл:** `sandbox-08/task4.cpp`

### Опис завдання

Реалізувати однозв'язний список, у якому кожен елемент містить число та вказівник на наступний елемент.

Програма повинна додавати нові елементи в кінець списку, виводити їхні значення, визначати кількість елементів та звільняти використану динамічну пам'ять.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task4.cpp -o /tmp/sandbox08-task4
/tmp/sandbox08-task4
```

### Результат перевірки

```text
1 2 3
3
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `1 2 3` та `3` | `1 2 3` та `3` | До списку додано три елементи, які виводяться в порядку додавання, після чого програма показує довжину списку. |

### Додаткові варіанти для демонстрації

Для зміни кількості елементів потрібно змінити межі циклу `for` у функції `main()`.

| Значення, які додаються | Очікуваний результат | Довжина |
|---|---|---|
| Від 1 до 3 | `1 2 3` | `3` |
| Від 1 до 5 | `1 2 3 4 5` | `5` |
| Від 1 до 1 | `1` | `1` |
| Від 2 до 5 | `2 3 4 5` | `4` |

Наприклад, змінити цикл на:

```cpp
for (int v = 1; v <= 5; ++v)
```

**Очікуваний результат:**

```text
1 2 3 4 5
5
```

Повторна компіляція та запуск:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task4.cpp -o /tmp/sandbox08-task4
/tmp/sandbox08-task4
```

Після завершення роботи програма звільняє динамічну пам'ять кожного елемента списку.

## Завдання 5. Контрольна сума GPS

**Файл:** `sandbox-08/task5.cpp`

### Опис завдання

Реалізувати перевірку контрольної суми GPS-повідомлення у форматі NMEA.

Програма обчислює контрольну суму символів між `$` та `*` і порівнює її зі значенням, записаним після `*`.

Перевіряються два повідомлення: правильне та змінене.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task5.cpp -o /tmp/sandbox08-task5
/tmp/sandbox08-task5
```

### Результат перевірки

```text
1 0
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `1 0` | `1 0` | Перше повідомлення має правильну контрольну суму, а в другому змінено символ без оновлення контрольної суми, тому перевірка не проходить. |

У результаті `1` означає успішну перевірку, а `0` — невідповідність контрольної суми або некоректний формат, який виявляє реалізована функція.

### Додаткові варіанти для демонстрації

У програмі вже є змінні `good` та `bad`, які містять правильне і змінене повідомлення.

Можна змінювати їхній порядок у функції `main()`.

| Перевірювані повідомлення | Очікуваний результат |
|---|---|
| `good`, `bad` | `1 0` |
| `good`, `good` | `1 1` |
| `bad`, `bad` | `0 0` |
| `bad`, `good` | `0 1` |

Наприклад, замінити рядок виведення на:

```cpp
std::cout << check_nmea(bad) << ' '
          << check_nmea(good) << '\n';
```

**Очікуваний результат:**

```text
0 1
```

Повторна компіляція та запуск:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task5.cpp -o /tmp/sandbox08-task5
/tmp/sandbox08-task5
```

## Завдання 6. Токени руками

**Файл:** `sandbox-08/task6.cpp`

### Опис завдання

Реалізувати простий лексичний аналізатор, який розбиває текстовий рядок на окремі елементи — токени.

Програма розпізнає три типи токенів:

- `Number` — послідовність цифр.
- `Ident` — послідовність малих латинських літер.
- `Punct` — окремий символ, який не належить до двох попередніх категорій.

Програма виводить тип кожного токена та його значення.

### Компіляція та запуск

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task6.cpp -o /tmp/sandbox08-task6
/tmp/sandbox08-task6
```

### Результат перевірки

```text
Ident(ab) Punct(=) Number(7)
Ident(count) Punct(=) Number(12) Punct(+) Ident(x)
```

| Очікуваний результат | Фактичний результат | Чому так |
|---|---|---|
| `Ident(ab) Punct(=) Number(7)` та `Ident(count) Punct(=) Number(12) Punct(+) Ident(x)` | Результат збігся з очікуваним | Програма правильно виділяє послідовності літер і цифр та окремо розпізнає знаки пунктуації. |

### Додаткові варіанти для демонстрації

Для перевірки інших текстових рядків потрібно змінювати виклики `tokenize()` у функції `main()`.

| Рядок | Очікувані токени |
|---|---|
| `"cat=5"` | `Ident(cat) Punct(=) Number(5)` |
| `"x+10"` | `Ident(x) Punct(+) Number(10)` |
| `"abc123"` | `Ident(abc) Number(123)` |
| `"a,b"` | `Ident(a) Punct(,) Ident(b)` |

Наприклад:

```cpp
int main() {
    tokenize("cat=5");
    tokenize("x+10");
}
```

**Очікуваний результат:**

```text
Ident(cat) Punct(=) Number(5)
Ident(x) Punct(+) Number(10)
```

Повторна компіляція та запуск:

```bash
g++ -std=c++17 -Wall -Wextra sandbox-08/task6.cpp -o /tmp/sandbox08-task6
/tmp/sandbox08-task6
```
